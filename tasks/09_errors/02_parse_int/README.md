## PY_09_02. Разбор числа

### Задание
| PY_09_02 ||
| ------ | ------- |
| **Темы:** | `try`, `except`, `ValueError` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Попробуй превратить строку в целое число. При успехе выведи
`Number: <число>`, иначе `Error: invalid number`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `42` | `Number: 42` |
| `abc` | `Error: invalid number` |
