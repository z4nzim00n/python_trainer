## PY_09_05. Индекс вне диапазона

### Задание
| PY_09_05 ||
| ------ | ------- |
| **Темы:** | `IndexError`, индексы, `try` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n` и индекс, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай список и индекс. Выведи элемент по индексу или сообщение
об ошибке:

~~~text
Value: <элемент>
~~~

~~~text
Error: index out of range
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 1`<br>`10 20 30` | `Value: 20` |
| `3 5`<br>`10 20 30` | `Error: index out of range` |
