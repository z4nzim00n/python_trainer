## PY_09_01. Безопасное деление

### Задание
| PY_09_01 ||
| ------ | ------- |
| **Темы:** | `try`, `except`, `ZeroDivisionError` |
| **Файл решения:** | main.py |
| **Входные данные:** | Два целых числа через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Раздели первое число на второе. Если делитель равен нулю, выведи
`Error: division by zero`, иначе `Result: <частное>`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `10 2` | `Result: 5.0` |
| `5 0` | `Error: division by zero` |
