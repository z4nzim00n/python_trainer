## PY_09_04. Контекстный менеджер

### Задание
| PY_09_04 ||
| ------ | ------- |
| **Темы:** | `with`, `__enter__`, `__exit__` |
| **Файл решения:** | main.py |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Resource`, который при входе в блок `with` печатает `Open`,
а при выходе — `Closed`. Внутри блока выведи `Using resource`:

~~~text
Open
Using resource
Closed
~~~

| Входные данные | Результат работы |

| *(нет ввода)* | `Open`<br>`Using resource`<br>`Closed` |
