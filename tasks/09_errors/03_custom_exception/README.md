## PY_09_03. Своё исключение

### Задание
| PY_09_03 ||
| ------ | ------- |
| **Темы:** | `Exception`, `raise`, `except` |
| **Файл решения:** | main.py |
| **Входные данные:** | Возраст (целое число) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши исключение `NegativeAgeError`. Если возраст меньше нуля, брось его
и выведи `Error: negative age`. Иначе выведи `Age: <возраст>`.

Обработку сделай через `try`/`except`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `36` | `Age: 36` |
| `-1` | `Error: negative age` |
