## PY_13_01. Обобщённый максимум

### Задание
| PY_13_01 ||
| ------ | ------- |
| **Темы:** | аннотации типов, `TypeVar`, `Sequence` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Напиши функцию `max_value`, которая возвращает максимальный элемент
последовательности. Используй аннотации типов и `TypeVar`. Выведи:

~~~text
Max: <число>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 7 2 9 4` | `Max: 9` |
| `1`<br>`-5` | `Max: -5` |

### Как проверить

```bash
bash run_tests13_1.sh
```
