## PY_13_04. Перегрузка операторов

### Задание
| PY_13_04 ||
| ------ | ------- |
| **Темы:** | `__add__`, `__str__`, dunder-методы |
| **Файл решения:** | main.py |
| **Входные данные:** | Два вектора (две строки) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Vector` с координатами `x` и `y`. Перегрузи `+` так,
чтобы векторы складывались, и `__str__` для вывода:

~~~text
(<x>, <y>)
~~~

Считай два вектора и выведи их сумму.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1 2`<br>`3 4` | `(4, 6)` |
| `0 0`<br>`0 0` | `(0, 0)` |

### Как проверить

```bash
bash run_tests13_4.sh
```
