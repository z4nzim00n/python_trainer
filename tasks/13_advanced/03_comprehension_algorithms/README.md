## PY_13_03. Генераторы и алгоритмы

### Задание
| PY_13_03 ||
| ------ | ------- |
| **Темы:** | генераторные выражения, `sum`, `filter`, `map` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай сумму квадратов чётных чисел:

~~~text
Sum: <сумма>
~~~

Например, для `1 2 3 4 5` ответ `20`: `2^2 + 4^2`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `Sum: 20` |
| `4`<br>`2 2 2 2` | `Sum: 16` |
| `3`<br>`1 3 5` | `Sum: 0` |
