## PY_13_02. Сортировка с лямбдой

### Задание
| PY_13_02 ||
| ------ | ------- |
| **Темы:** | `lambda`, `key`, сортировка кортежей |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` строк «имя балл» |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Отсортируй участников по баллам по убыванию. При равных баллах —
по имени по возрастанию. Выведи:

~~~text
<имя>: <балл>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3`<br>`Ada 90`<br>`Bob 75`<br>`Cy 90` | `Ada: 90`<br>`Cy: 90`<br>`Bob: 75` |
| `2`<br>`Zoe 100`<br>`Amy 100` | `Amy: 100`<br>`Zoe: 100` |

### Как проверить

```bash
bash run_tests13_2.sh
```
