# PY_13_02. Сортировка с лямбдой — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests13_2.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `3\nAda 90\nBob 75\nCy 90` | `Ada: 90\nCy: 90\nBob: 75\n` |
| `2\nZoe 100\nAmy 100` | `Amy: 100\nZoe: 100\n` |
| `3\nL 5\nM 9\nN 1` | `M: 9\nL: 5\nN: 1\n` |
