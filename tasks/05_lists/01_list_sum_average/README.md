## PY_05_01. Сумма и среднее

### Задание
| PY_05_01 ||
| ------ | ------- |
| **Темы:** | список, `sum`, `len`, `float` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай список чисел и выведи сумму и среднее арифметическое:

~~~text
Sum: <сумма>
Average: <среднее с двумя знаками>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4`<br>`1 2 3 4` | `Sum: 10`<br>`Average: 2.50` |
| `3`<br>`2 2 2` | `Sum: 6`<br>`Average: 2.00` |

### Как проверить

```bash
bash run_tests5_1.sh
```
