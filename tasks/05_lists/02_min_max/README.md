## PY_05_02. Минимум и максимум

### Задание
| PY_05_02 ||
| ------ | ------- |
| **Темы:** | `min`, `max`, список |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди минимальное и максимальное значения списка:

~~~text
Min: <минимум>
Max: <максимум>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 7 2 9 4` | `Min: 2`<br>`Max: 9` |
| `3`<br>`-4 -1 -9` | `Min: -9`<br>`Max: -1` |

### Как проверить

```bash
bash run_tests5_2.sh
```
