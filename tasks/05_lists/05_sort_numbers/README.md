## PY_05_05. Сортировка

### Задание
| PY_05_05 ||
| ------ | ------- |
| **Темы:** | `sorted`, `sort`, порядок |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Отсортируй числа по возрастанию и выведи их через пробел:

~~~text
<числа по возрастанию>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 1 4 1 5` | `1 1 3 4 5` |
| `3`<br>`-1 5 0` | `-1 0 5` |

### Как проверить

```bash
bash run_tests5_5.sh
```
