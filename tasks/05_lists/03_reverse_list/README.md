## PY_05_03. Разворот списка

### Задание
| PY_05_03 ||
| ------ | ------- |
| **Темы:** | срезы, `reversed`, список |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи элементы списка в обратном порядке через пробел:

~~~text
<последний> ... <первый>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4`<br>`1 2 3 4` | `4 3 2 1` |
| `1`<br>`10` | `10` |
