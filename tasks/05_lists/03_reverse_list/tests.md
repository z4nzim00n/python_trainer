# PY_05_03. Разворот списка — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests5_3.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `4\n1 2 3 4` | `4 3 2 1\n` |
| `1\n10` | `10\n` |
| `3\n-1 0 5` | `5 0 -1\n` |

## Автотесты

bash run_tests5_3.sh
