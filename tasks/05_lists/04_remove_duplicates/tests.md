# PY_05_04. Удаление дубликатов — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests5_4.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `6\n1 2 3 1 2 4` | `1 2 3 4\n` |
| `5\n5 5 5 5 5` | `5\n` |
| `4\n3 1 3 1` | `3 1\n` |

## Автотесты
