## PY_05_04. Удаление дубликатов

### Задание
| PY_05_04 ||
| ------ | ------- |
| **Темы:** | `set`, порядок элементов, список |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Убери повторяющиеся числа, сохранив порядок первого появления:

~~~text
<уникальные числа через пробел>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `6`<br>`1 2 3 1 2 4` | `1 2 3 4` |
| `5`<br>`5 5 5 5 5` | `5` |

```bash
bash run_tests5_4.sh
```
