## PY_12_04. Гистограмма

### Задание
| PY_12_04 ||
| ------ | ------- |
| **Темы:** | `Counter`, `sorted`, умножение строк |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` положительных чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Построй горизонтальную гистограмму: для каждого значения выведи его
и столько звёздочек, сколько раз оно встретилось:

~~~text
<значение>: <звёздочки>
~~~

Строки идут по возрастанию значения.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `6`<br>`1 2 2 3 3 3` | `1: *`<br>`2: **`<br>`3: ***` |
| `3`<br>`5 5 5` | `5: ***` |

### Как проверить

bash run_tests12_4.sh
