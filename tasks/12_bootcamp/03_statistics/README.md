## PY_12_03. Статистика

### Задание
| PY_12_03 ||
| ------ | ------- |
| **Темы:** | `sum`, `min`, `max`, `len`, форматирование |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи статистику списка:

~~~text
Count: <количество>
Sum: <сумма>
Min: <минимум>
Max: <максимум>
Average: <среднее с двумя знаками>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `Count: 5`<br>`Sum: 15`<br>`Min: 1`<br>`Max: 5`<br>`Average: 3.00` |
| `1`<br>`7` | `Count: 1`<br>`Sum: 7`<br>`Min: 7`<br>`Max: 7`<br>`Average: 7.00` |

### Как проверить

```bash
bash run_tests12_3.sh
```
