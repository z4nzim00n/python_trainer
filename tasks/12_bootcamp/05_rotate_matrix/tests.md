# PY_12_05. Поворот матрицы — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests12_5.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `2\n1 2\n3 4` | `3 1\n4 2\n` |
| `3\n1 2 3\n4 5 6\n7 8 9` | `7 4 1\n8 5 2\n9 6 3\n` |
| `1\n42` | `42\n` |

## Автотесты

```bash
bash run_tests12_5.sh
```
