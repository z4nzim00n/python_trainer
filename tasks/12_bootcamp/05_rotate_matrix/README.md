## PY_12_05. Поворот матрицы

### Задание
| PY_12_05 ||
| ------ | ------- |
| **Темы:** | вложенные списки, `zip`, срезы |
| **Файл решения:** | main.py |
| **Входные данные:** | Размер `n`, затем `n` строк матрицы |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поверни квадратную матрицу на 90 градусов по часовой стрелке и выведи
результат:

~~~text
<новая строка 1>
...
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2`<br>`1 2`<br>`3 4` | `3 1`<br>`4 2` |
| `3`<br>`1 2 3`<br>`4 5 6`<br>`7 8 9` | `7 4 1`<br>`8 5 2`<br>`9 6 3` |

### Как проверить

```bash
bash run_tests12_5.sh
```
