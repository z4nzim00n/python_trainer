## PY_12_01. Простое число

### Задание
| PY_12_01 ||
| ------ | ------- |
| **Темы:** | `while`, делители, `bool` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Определи, является ли число простым:

~~~text
Prime: <True/False>
~~~

Простое число больше единицы и делится только на `1` и на себя.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `17` | `Prime: True` |
| `9` | `Prime: False` |
| `1` | `Prime: False` |
