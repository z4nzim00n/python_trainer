## PY_12_06. Сумма матриц

### Задание
| PY_12_06 ||
| ------ | ------- |
| **Темы:** | вложенные списки, генераторы, `zip` |
| **Файл решения:** | main.py |
| **Входные данные:** | Размер `n`, затем две матрицы `n x n` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сложи две матрицы поэлементно и выведи результат:

~~~text
<строка 1>
...
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2`<br>`1 2`<br>`3 4`<br>`5 6`<br>`7 8` | `6 8`<br>`10 12` |
