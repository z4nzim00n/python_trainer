# PY_12_06. Сумма матриц — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests12_6.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `2\n1 2\n3 4\n5 6\n7 8` | `6 8\n10 12\n` |
| `1\n5\n6` | `11\n` |
| `2\n1 -1\n0 2\n-1 1\n0 -2` | `0 0\n0 0\n` |
