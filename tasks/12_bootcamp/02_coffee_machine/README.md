## PY_12_02. Кофейный автомат

### Задание
| PY_12_02 ||
| ------ | ------- |
| **Темы:** | `for`, `break`, накопление суммы |
| **Файл решения:** | main.py |
| **Входные данные:** | Цена и монеты (две строки) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Автомат принимает монеты, пока не встретит `0`. Сравни оплату с ценой:

- если денег достаточно, выведи `Change: <сдача>`;
- если нет — `Need: <не хватает>`.

Монеты после нуля игнорируются.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `50`<br>`10 10 10 10 10 0` | `Change: 0` |
| `75`<br>`25 25 0` | `Need: 25` |

### Как проверить

```bash
bash run_tests12_2.sh
```
