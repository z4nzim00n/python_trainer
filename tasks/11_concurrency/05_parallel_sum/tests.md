# PY_11_05. Параллельная сумма — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests11_5.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `6\n1 2 3 4 5 6` | `Sum: 21\n` |
| `1\n10` | `Sum: 10\n` |
| `5\n-1 1 -2 2 0` | `Sum: 0\n` |

## Автотесты

```bash
bash run_tests11_5.sh
```
