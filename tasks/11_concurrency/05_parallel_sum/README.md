## PY_11_05. Параллельная сумма

### Задание
| PY_11_05 ||
| ------ | ------- |
| **Темы:** | `Thread`, части списка, `sum` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Раздели список на две половины и посчитай суммы в двух потоках.
Выведи общую сумму:

~~~text
Sum: <сумма>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `6`<br>`1 2 3 4 5 6` | `Sum: 21` |
| `1`<br>`10` | `Sum: 10` |

bash run_tests11_5.sh
