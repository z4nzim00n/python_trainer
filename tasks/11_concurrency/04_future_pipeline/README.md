## PY_11_04. Пул потоков

### Задание
| PY_11_04 ||
| ------ | ------- |
| **Темы:** | `ThreadPoolExecutor`, `submit`, `Future.result` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число `n` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Вычисли квадраты чисел от `1` до `n` в пуле потоков. Выведи результаты
в порядке возрастания чисел:

~~~text
Results: 1 4 9 ...
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3` | `Results: 1 4 9` |
| `5` | `Results: 1 4 9 16 25` |

### Как проверить

```bash
bash run_tests11_4.sh
```
