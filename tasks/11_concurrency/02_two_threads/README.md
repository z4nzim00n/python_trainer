## PY_11_02. Два потока

### Задание
| PY_11_02 ||
| ------ | ------- |
| **Темы:** | `Thread`, `args`, общий список |
| **Файл решения:** | main.py |
| **Входные данные:** | Два целых числа `a` и `b` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай квадраты `a` и `b` в двух разных потоках. Выведи результаты:

~~~text
A: 4
B: 9
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2 3` | `A: 4`<br>`B: 9` |
| `-4 5` | `A: 16`<br>`B: 25` |

### Как проверить

```bash
bash run_tests11_2.sh
```
