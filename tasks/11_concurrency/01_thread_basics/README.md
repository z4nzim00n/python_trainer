## PY_11_01. Первый поток

### Задание
| PY_11_01 ||
| ------ | ------- |
| **Темы:** | `threading.Thread`, `start`, `join` |
| **Файл решения:** | main.py |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Запусти поток, который печатает `Hello from thread`, дождись его
завершения и напечатай `Main done`:

~~~text
Hello from thread
Main done
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| *(нет ввода)* | `Hello from thread`<br>`Main done` |
