## PY_11_03. Счётчик с замком

### Задание
| PY_11_03 ||
| ------ | ------- |
| **Темы:** | `Lock`, `with lock`, гонка данных |
| **Файл решения:** | main.py |
| **Входные данные:** | Количество потоков и число прибавлений |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Запусти указанное число потоков. Каждый поток увеличивает общий счётчик
заданное число раз. Выведи итог:

~~~text
Counter: <значение>
~~~

Используй `threading.Lock`, чтобы прибавления не терялись.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4 1000` | `Counter: 4000` |
| `2 5` | `Counter: 10` |

### Как проверить

```bash
bash run_tests11_3.sh
```
