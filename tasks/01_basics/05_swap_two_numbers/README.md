## PY_01_05. Обмен значений

### Задание
| PY_01_05 ||
| ------ | ------- |
| **Темы:** | `input`, `split`, `map`, кортежи |
| **Файл решения:** | main.py |
| **Входные данные:** | Два целых числа через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два целых числа и выведи их в обратном порядке через пробел:

~~~text
<b> <a>
~~~

Например, для `3 5` вывод должен быть `5 3`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 5` | `5 3` |
| `-1 10` | `10 -1` |

### Как проверить

```bash
bash run_tests1_5.sh
```
