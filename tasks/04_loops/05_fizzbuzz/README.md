## PY_04_05. FizzBuzz

### Задание
| PY_04_05 ||
| ------ | ------- |
| **Темы:** | `for`, `range`, `%`, `elif` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число `n` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи числа от 1 до `n`. Вместо чисел, кратных 3, печатай `Fizz`,
вместо кратных 5 — `Buzz`, вместо кратных и 3, и 5 — `FizzBuzz`:

~~~text
1
2
Fizz
4
Buzz
...
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5` | `1`<br>`2`<br>`Fizz`<br>`4`<br>`Buzz` |
| `15` | ...<br>`FizzBuzz` |

### Как проверить

```bash
bash run_tests4_5.sh
```
