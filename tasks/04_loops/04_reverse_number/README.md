## PY_04_04. Разворот числа

### Задание
| PY_04_04 ||
| ------ | ------- |
| **Темы:** | `while`, цифры, знак числа |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Разверни цифры числа и выведи результат:

~~~text
Reversed: <число>
~~~

Ведущие нули не печатаются: для `1200` получается `21`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `123` | `Reversed: 321` |
| `1200` | `Reversed: 21` |
| `-45` | `Reversed: -54` |

```bash
bash run_tests4_4.sh
```
