## PY_04_01. Максимум последовательности

### Задание
| PY_04_01 ||
| ------ | ------- |
| **Темы:** | `for`, список, `max` |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `n`, затем `n` целых чисел и выведи максимальное:

~~~text
Max: <число>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 7 2 9 4` | `Max: 9` |
| `1`<br>`-5` | `Max: -5` |
