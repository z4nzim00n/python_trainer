## PY_04_02. Сумма цифр

### Задание
| PY_04_02 ||
| ------ | ------- |
| **Темы:** | `while`, `%`, `//`, `abs` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи сумму его цифр:

~~~text
Sum: <сумма>
~~~

Знак числа не влияет на сумму: для `-47` сумма равна `11`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `123` | `Sum: 6` |
| `9005` | `Sum: 14` |
| `-47` | `Sum: 11` |

### Как проверить

```bash
bash run_tests4_2.sh
```
