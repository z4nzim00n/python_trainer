## PY_04_06. Непарное число

### Задание
| PY_04_06 ||
| ------ | ------- |
| **Темы:** | `for`, XOR `^`, поиск пары |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


В последовательности каждое число встречается дважды, кроме одного.
Найди и выведи его:

~~~text
Unpaired: <число>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 2 1` | `Unpaired: 3` |
| `1`<br>`42` | `Unpaired: 42` |

```bash
bash run_tests4_6.sh
```
