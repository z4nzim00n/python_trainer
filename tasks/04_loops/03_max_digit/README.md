## PY_04_03. Максимальная цифра

### Задание
| PY_04_03 ||
| ------ | ------- |
| **Темы:** | `while`, сравнение, цифры числа |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи его максимальную цифру:

~~~text
Max digit: <цифра>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `123` | `Max digit: 3` |
| `9005` | `Max digit: 9` |
| `-47` | `Max digit: 7` |
