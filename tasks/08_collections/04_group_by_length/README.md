## PY_08_04. Группировка по длине

### Задание
| PY_08_04 ||
| ------ | ------- |
| **Темы:** | `dict`, `setdefault`, списки значений |
| **Файл решения:** | main.py |
| **Входные данные:** | Слова через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сгруппируй слова по длине и выведи группы по возрастанию длины:

~~~text
<длина>: <слова через пробел>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `cat dog hello` | `3: cat dog`<br>`5: hello` |
| `a bb ccc` | `1: a`<br>`2: bb`<br>`3: ccc` |

### Как проверить

```bash
bash run_tests8_4.sh
```
