## PY_08_03. Уникальные элементы

### Задание
| PY_08_03 ||
| ------ | ------- |
| **Темы:** | `set`, `sorted`, множество |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи уникальные числа в порядке возрастания:

~~~text
Unique: <числа через пробел>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `6`<br>`3 1 2 1 3 2` | `Unique: 1 2 3` |
| `4`<br>`-1 -1 0 0` | `Unique: -1 0` |
