# PY_08_03. Уникальные элементы — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests8_3.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `6\n3 1 2 1 3 2` | `Unique: 1 2 3\n` |
| `1\n5` | `Unique: 5\n` |
| `4\n-1 -1 0 0` | `Unique: -1 0\n` |

## Автотесты
