## PY_08_02. Поиск в словаре

### Задание
| PY_08_02 ||
| ------ | ------- |
| **Темы:** | `dict`, `in`, `get`, `KeyError` |
| **Файл решения:** | main.py |
| **Входные данные:** | Ключ |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Дан словарь:

~~~python
data = {"name": "Ada", "lang": "Python", "year": "1991"}
~~~

Считай ключ. Если он есть, выведи `Value: <значение>`, иначе
`Value: Not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `name` | `Value: Ada` |
| `age` | `Value: Not found` |

bash run_tests8_2.sh
