## PY_08_05. Инверсия словаря

### Задание
| PY_08_05 ||
| ------ | ------- |
| **Темы:** | `dict`, `setdefault`, группировка |
| **Файл решения:** | main.py |
| **Входные данные:** | Число `n`, затем `n` пар «ключ значение» |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Построй обратный словарь: значению соответствует список ключей.
Выведи значения по возрастанию:

~~~text
<значение>: <ключи через пробел>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3`<br>`a 1`<br>`b 2`<br>`c 1` | `1: a c`<br>`2: b` |
| `3`<br>`m 10`<br>`n 2`<br>`o 10` | `2: n`<br>`10: m o` |

### Как проверить

bash run_tests8_5.sh
