## PY_08_01. Подсчёт слов

### Задание
| PY_08_01 ||
| ------ | ------- |
| **Темы:** | `dict`, `Counter`, сортировка ключей |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Посчитай, сколько раз встречается каждое слово, и выведи результат
по алфавиту:

~~~text
<слово>: <количество>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `apple banana apple` | `apple: 2`<br>`banana: 1` |
| `b a b a c` | `a: 2`<br>`b: 2`<br>`c: 1` |

bash run_tests8_1.sh
