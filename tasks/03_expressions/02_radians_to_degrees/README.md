## PY_03_02. Радианы в градусы

### Задание
| PY_03_02 ||
| ------ | ------- |
| **Темы:** | `math.degrees`, `float` |
| **Файл решения:** | main.py |
| **Входные данные:** | Угол в радианах |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Переведи угол из радиан в градусы и выведи результат с двумя знаками:

~~~text
Degrees: <градусы>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3.141592653589793` | `Degrees: 180.00` |
| `1.5707963267948966` | `Degrees: 90.00` |
