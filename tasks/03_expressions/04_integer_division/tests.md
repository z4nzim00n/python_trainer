# PY_03_04. Деление с остатком — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests3_4.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `7 3` | `Div: 2\nRem: 1\n` |
| `10 2` | `Div: 5\nRem: 0\n` |
| `-7 3` | `Div: -3\nRem: 2\n` |
