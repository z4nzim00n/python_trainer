## PY_03_04. Деление с остатком

### Задание
| PY_03_04 ||
| ------ | ------- |
| **Темы:** | `//`, `%`, `divmod` |
| **Файл решения:** | main.py |
| **Входные данные:** | Два целых числа через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два целых числа и выведи частное и остаток от деления:

~~~text
Div: <частное>
Rem: <остаток>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `7 3` | `Div: 2`<br>`Rem: 1` |
| `10 2` | `Div: 5`<br>`Rem: 0` |
