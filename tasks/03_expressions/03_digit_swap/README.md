## PY_03_03. Обмен цифр

### Задание
| PY_03_03 ||
| ------ | ------- |
| **Темы:** | `//`, `%`, целочисленная арифметика |
| **Файл решения:** | main.py |
| **Входные данные:** | Двузначное целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поменяй цифры двузначного числа местами и выведи результат:

~~~text
Swapped: <число>
~~~

Например, для `47` получится `74`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `47` | `Swapped: 74` |
| `10` | `Swapped: 1` |

### Как проверить

```bash
bash run_tests3_3.sh
```
