## PY_03_01. Площадь круга

### Задание
| PY_03_01 ||
| ------ | ------- |
| **Темы:** | `math.pi`, `float`, возведение в степень |
| **Файл решения:** | main.py |
| **Входные данные:** | Радиус (дробное число) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай радиус круга и выведи его площадь с двумя знаками после точки:

~~~text
Area: <площадь>
~~~

Формула: `S = pi * r^2`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1` | `Area: 3.14` |
| `2` | `Area: 12.57` |

bash run_tests3_1.sh
