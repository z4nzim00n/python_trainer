## PY_03_05. Логические выражения

### Задание
| PY_03_05 ||
| ------ | ------- |
| **Темы:** | `bool`, сравнения, `and`, `or`, `not` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи два признака:

~~~text
Positive: <True/False>
Even: <True/False>
~~~

`Positive` — число больше нуля. `Even` — число делится на 2 без остатка.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4` | `Positive: True`<br>`Even: True` |
| `-3` | `Positive: False`<br>`Even: False` |
| `0` | `Positive: False`<br>`Even: True` |

bash run_tests3_5.sh
