## PY_07_04. Метод `__str__`

### Задание
| PY_07_04 ||
| ------ | ------- |
| **Темы:** | `__str__`, `print`, строковое представление |
| **Файл решения:** | main.py |
| **Входные данные:** | Координаты `x` и `y` через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Point` с полями `x` и `y`. Метод `__str__` должен
возвращать:

~~~text
Point(<x>, <y>)
~~~

Считай координаты и выведи объект через `print`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 4` | `Point(3, 4)` |
| `-1 0` | `Point(-1, 0)` |

bash run_tests7_4.sh
