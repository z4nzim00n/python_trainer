## PY_07_02. Метод площади

### Задание
| PY_07_02 ||
| ------ | ------- |
| **Темы:** | класс, метод, арифметика |
| **Файл решения:** | main.py |
| **Входные данные:** | Ширина и высота через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Rectangle` с полями `width` и `height` и методом `area`,
который возвращает площадь. Считай размеры и выведи:

~~~text
Area: <площадь>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 4` | `Area: 12` |
| `5 5` | `Area: 25` |

bash run_tests7_2.sh
