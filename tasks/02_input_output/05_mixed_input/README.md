## PY_02_05. Смешанный ввод

### Задание
| PY_02_05 ||
| ------ | ------- |
| **Темы:** | `input`, `int`, чтение нескольких строк |
| **Файл решения:** | main.py |
| **Входные данные:** | Число и строка (две строки) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сначала считай целое число, затем строку. Выведи:

~~~text
<имя>: <число>
~~~

Например, для:

~~~text
3
Ada
~~~

вывод должен быть `Ada: 3`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3`<br>`Ada` | `Ada: 3` |
| `42`<br>`Bob` | `Bob: 42` |

bash run_tests2_5.sh
