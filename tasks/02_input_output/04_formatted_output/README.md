## PY_02_04. Форматирование числа

### Задание
| PY_02_04 ||
| ------ | ------- |
| **Темы:** | `float`, f-строки, формат `:.2f` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно дробное число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай дробное число и выведи его с двумя знаками после запятой:

~~~text
Value: 3.14
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3.14159` | `Value: 3.14` |
| `2` | `Value: 2.00` |

bash run_tests2_4.sh
