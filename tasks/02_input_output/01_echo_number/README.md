## PY_02_01. Эхо числа

### Задание
| PY_02_01 ||
| ------ | ------- |
| **Темы:** | `input`, `int`, f-строки |
| **Файл решения:** | main.py |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи его в формате:

~~~text
Number: <число>
~~~

Например, для `42` вывод `Number: 42`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `42` | `Number: 42` |
| `-7` | `Number: -7` |

### Как проверить

```bash
bash run_tests2_1.sh
```
