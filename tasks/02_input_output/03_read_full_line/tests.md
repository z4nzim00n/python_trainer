# PY_02_03. Строка целиком — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests2_3.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `hello world` | `Line: hello world\n` |
| `a b c` | `Line: a b c\n` |
| `` (пустая строка) | `Line: \n` |

## Автотесты

```bash
bash run_tests2_3.sh
```
