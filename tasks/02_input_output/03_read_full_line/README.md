## PY_02_03. Строка целиком

### Задание
| PY_02_03 ||
| ------ | ------- |
| **Темы:** | `input`, пробелы в строке |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка текста |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку целиком, включая пробелы, и выведи её в формате:

~~~text
Line: <строка>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello world` | `Line: hello world` |
| `a b c` | `Line: a b c` |

bash run_tests2_3.sh
