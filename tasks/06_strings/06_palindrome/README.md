## PY_06_06. Палиндром

### Задание
| PY_06_06 ||
| ------ | ------- |
| **Темы:** | нормализация строки, срез, `isalnum` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Проверь, является ли строка палиндромом. Игнорируй регистр и символы,
кроме букв и цифр:

~~~text
Palindrome: <True/False>
~~~

Например, `A man a plan a canal Panama` — палиндром.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `level` | `Palindrome: True` |
| `Hello` | `Palindrome: False` |
| `A man a plan a canal Panama` | `Palindrome: True` |
