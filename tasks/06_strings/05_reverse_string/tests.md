# PY_06_05. Разворот строки — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests6_5.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `hello` | `olleh\n` |
| `abc def` | `fed cba\n` |
| `` (пустая строка) | `\n` |

## Автотесты

```bash
bash run_tests6_5.sh
```
