## PY_06_03. Верхний и нижний регистр

### Задание
| PY_06_03 ||
| ------ | ------- |
| **Темы:** | `upper`, `lower`, строки |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи строку в верхнем и нижнем регистре:

~~~text
Upper: <ЗАГЛАВНЫЕ>
Lower: <строчные>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `Hello` | `Upper: HELLO`<br>`Lower: hello` |
| `PyThOn` | `Upper: PYTHON`<br>`Lower: python` |
