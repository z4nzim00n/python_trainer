# PY_06_01. Длина строки — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests6_1.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `hello` | `Length: 5\n` |
| `a b` | `Length: 3\n` |
| `` (пустая строка) | `Length: 0\n` |

## Автотесты

```bash
bash run_tests6_1.sh
```
