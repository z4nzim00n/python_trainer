## PY_06_01. Длина строки

### Задание
| PY_06_01 ||
| ------ | ------- |
| **Темы:** | `len`, строки, `input` |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай строку и выведи её длину:

~~~text
Length: <длина>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello` | `Length: 5` |
| `a b` | `Length: 3` |
