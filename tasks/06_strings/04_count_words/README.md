## PY_06_04. Количество слов

### Задание
| PY_06_04 ||
| ------ | ------- |
| **Темы:** | `split`, пробельные символы |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай количество слов в строке:

~~~text
Words: <количество>
~~~

Слова разделены пробелами; лишние пробелы не создают пустых слов.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello world` | `Words: 2` |
| `  a   b  c  ` | `Words: 3` |
