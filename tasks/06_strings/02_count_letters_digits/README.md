## PY_06_02. Буквы и цифры

### Задание
| PY_06_02 ||
| ------ | ------- |
| **Темы:** | `isalpha`, `isdigit`, цикл по строке |
| **Файл решения:** | main.py |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай, сколько в строке букв и сколько цифр:

~~~text
Letters: <количество букв>
Digits: <количество цифр>
~~~

Пробелы и знаки препинания не считаются.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `abc123` | `Letters: 3`<br>`Digits: 3` |
| `Hello, World!` | `Letters: 10`<br>`Digits: 0` |

bash run_tests6_2.sh
