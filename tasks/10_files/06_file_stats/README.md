## PY_10_06. Статистика файла

### Задание
| PY_10_06 ||
| ------ | ------- |
| **Темы:** | `read`, `splitlines`, строки и слова |
| **Файл решения:** | main.py |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай строки, слова и символы (без переводов строк):

~~~text
Lines: <строк>
Words: <слов>
Chars: <символов>
~~~

Если файла нет, выведи `Error: file not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `text.txt` (`hello world\npython\n`) | `Lines: 2`<br>`Words: 3`<br>`Chars: 17` |
| `text.txt` (`abc`) | `Lines: 1`<br>`Words: 1`<br>`Chars: 3` |

### Как проверить

```bash
bash run_tests10_6.sh
```
