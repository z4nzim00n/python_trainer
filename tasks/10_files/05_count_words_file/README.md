## PY_10_05. Слова в файле

### Задание
| PY_10_05 ||
| ------ | ------- |
| **Темы:** | `read`, `split`, `len` |
| **Файл решения:** | main.py |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай количество слов в файле:

~~~text
Words: <количество>
~~~

Если файла нет, выведи `Error: file not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `text.txt` (`hello world\npython`) | `Words: 3` |
| `text.txt` (`one`) | `Words: 1` |

### Как проверить

```bash
bash run_tests10_5.sh
```
