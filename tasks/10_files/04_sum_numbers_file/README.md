## PY_10_04. Сумма чисел из файла

### Задание
| PY_10_04 ||
| ------ | ------- |
| **Темы:** | `read`, `split`, `map`, `sum` |
| **Файл решения:** | main.py |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


В файле записаны целые числа через пробелы и переводы строк. Посчитай
их сумму:

~~~text
Sum: <сумма>
~~~

Если файла нет, выведи `Error: file not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `numbers.txt` (`1 2 3\n4 5`) | `Sum: 15` |
| `numbers.txt` (`10`) | `Sum: 10` |

### Как проверить

```bash
bash run_tests10_4.sh
```
