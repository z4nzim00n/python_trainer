## PY_10_03. Копирование файла

### Задание
| PY_10_03 ||
| ------ | ------- |
| **Темы:** | чтение, запись, `FileNotFoundError` |
| **Файл решения:** | main.py |
| **Входные данные:** | Имя исходного и нового файла (две строки) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Скопируй содержимое одного файла в другой и выведи:

~~~text
Copied: <источник> -> <назначение>
~~~

Если исходного файла нет, выведи `Error: file not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `input.txt`<br>`copy.txt` | `Copied: input.txt -> copy.txt` |

### Как проверить

```bash
bash run_tests10_3.sh
```
