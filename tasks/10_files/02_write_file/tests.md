# PY_10_02. Запись файла — Тесты

## Запуск

```bash
python main.py
```

Эталон:

```bash
python solution.py
python solution_commented.py
```

Скрипт `run_tests10_2.sh` сам находит интерпретатор Python 3.

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `output.txt\nhello` | `Written: output.txt\n`, файл `hello` |
| `text.txt\nhello world` | `Written: text.txt\n`, файл `hello world` |

## Автотесты

```bash
bash run_tests10_2.sh
```
