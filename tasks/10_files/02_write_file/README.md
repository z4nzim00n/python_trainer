## PY_10_02. Запись файла

### Задание
| PY_10_02 ||
| ------ | ------- |
| **Темы:** | `open`, режим `"w"`, `write` |
| **Файл решения:** | main.py |
| **Входные данные:** | Имя файла и строка (две строки) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Запиши строку в файл и подтверди:

~~~text
Written: <имя файла>
~~~

Если файл уже существовал, он перезаписывается.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `output.txt`<br>`hello` | `Written: output.txt` |

### Как проверить

```bash
bash run_tests10_2.sh
```
