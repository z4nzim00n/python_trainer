# Python Trainer — путь с нуля

Тренажёр по Python для тех, кто раньше не писал на этом языке. 13 разделов,
71 задание: от первой строки `print("Hello, Python!")` до потоков,
файлов и генераторов.

Каждое задание — отдельная папка с условием, теорией, тестами, заготовкой,
эталонным решением и решением с комментариями. Всё проверяется побайтовым
сравнением вывода, поэтому «почти правильно» не засчитывается.

---

## Быстрый старт

### 1. Что нужно

Интерпретатор **Python 3.10 или новее**. Проверь, что он доступен:

```bash
python --version
```

Если команда `python` не найдена, попробуй `py --version` (лаунчер
Windows) или `python3 --version` (Linux/macOS).

Скрипты тренажёра ищут интерпретатор в таком порядке:

1. переменная окружения `PYTHON`, если задана;
2. `python`;
3. `py`;
4. `python3`.

Если Python установлен в нестандартном месте, задай `PYTHON` полным путём:

```bash
export PYTHON="/c/Users/me/AppData/Local/Programs/Python/Python313/python.exe"
```

> Не полагайся на `python3`: в Windows это часто заглушка Microsoft Store,
> которая открывает магазин вместо запуска.

### 2. Как проходить задание

Из корня `python_trainer` в Git Bash:

```bash
cd tasks/01_basics/01_hello_world
bash run_tests1_1.sh
```

Но сначала — руками:

```bash
python main.py
```

Ожидаемый вывод:

```text
Hello, Python!
```

Порядок работы:

1. Открой `README.md` — там условие и примеры.
2. Прочитай `theory.md` — короткий разбор темы.
3. Открой `main.py`, найди `# TODO` и допиши программу.
4. Запусти программу и сравни с примерами.
5. Проверь себя автотестом: `bash run_tests1_1.sh`.
6. Если не получается — посмотри `solution.py` и
   `solution_commented.py`.

### 3. Проверка всех заданий

```bash
cd python_trainer
bash scripts/run_all.sh --solution
bash scripts/run_all.sh --commented
```

Обе команды должны напечатать:

```text
Пройдено: 71/71
```

### Что внутри по разделам

**01. Основы.** `print`, строки, отступы вместо скобок, переменные,
`f-strings`, исправление намеренно сломанного кода, обмен значений.

**02. Ввод и вывод.** `input`, `int`, `split`, `map`, `print` с `sep` и
`end`, форматирование чисел, смешанный ввод.

**03. Выражения.** Целочисленное деление `//`, остаток `%`, `math.pi`,
`round`, срезы чисел, `and`/`or`/`not`.

**04. Циклы.** `for`, `while`, `range`, `break`/`continue`, `for` по строке,
цифры числа, FizzBuzz, XOR.

**05. Списки.** `append`, срезы, `len`, `sum`, `min`/`max`, `sorted`,
`set`, `list`, циклический сдвиг.

**06. Строки.** `len`, методы `isalpha`/`isdigit`, `upper`/`lower`,
`split`, `join`, разворот через срез, палиндром, шифр Цезаря.

**07. Классы.** `class`, `__init__`, `self`, методы, `__str__`,
наследование, `super()`, абстрактные классы через `abc`.

**08. Коллекции.** `dict`, `get`, `set`, `Counter`, `defaultdict`,
подсчёт частот, группировка, инверсия словаря.

**09. Ошибки.** `try`/`except`, `else`/`finally`, `ValueError`,
своё исключение, контекстный менеджер, `IndexError`.

**10. Файлы.** `open`, `read`, `write`, `with`, `shutil.copy`,
построчное чтение, разбор чисел, подсчёт слов, статистика файла.

**11. Потоки.** `threading.Thread`, `start`/`join`, `Lock`, общий счётчик,
`ThreadPoolExecutor`, `Future`, параллельные суммы.

**12. Bootcamp.** Простые числа, кофейный автомат, статистика,
гистограмма, поворот матрицы, сумма матриц.

**13. Advanced.** `TypeVar`, дженерик-функции, сортировка по ключу,
генераторные выражения, перегрузка операторов.

## HTML-инструменты

### trainer.html

Просмотрщик заданий. Открой файл в браузере (Chrome или Edge), нажми
«Выбрать папку проекта» и укажи папку `tasks`. Слева появится дерево
разделов и заданий.

Что можно смотреть:

- условие (`README.md`);
- теорию;
- тесты;
- заготовку `main.py`;
- решение `solution.py` и решение с комментариями
  `solution_commented.py`.

Настройки темы и размера шрифта сохраняются в `localStorage`.
Подсветка синтаксиса понимает Python: комментарии, строки (включая
тройные и f-строки), декораторы, `__dunder__`, ключевые слова и числа.

> Просмотрщик читает файлы через File System Access API, поэтому нужен
> современный Chromium-браузер. Из `file://` папку выбрать можно, но при
> открытии страницы в Firefox дерево не появится.

### trainer_theory_tests.html

72 вопроса по 12 темам. Можно выбрать тему или собрать случайный набор.
После каждого ответа показывается разбор. Отдельный блок — генераторы
и типизация (раздел 13).

## Как проверяются задания

Автотест запускает файл и сравнивает **точные байты** вывода. Переводы
строк `\r\n` нормализуются в `\n`, чтобы Windows и Linux давали
одинаковый результат:

```bash
SOURCE_FILE=solution.py bash run_tests5_1.sh
```

- `run_case "вход" $'ожидание\n'` — вход через `printf`, ожидание
  в ANSI-C кавычках;
- `run_case_noeol` — без завершающего `\n`;
- `run_case_devnull` — пустой stdin;
- `run_case_args` — аргументы командной строки;
- `check_file` — файл, созданный программой.

Перед запуском скрипт проверяет синтаксис через `compile(...)`. Это
быстрее обычного запуска и не создаёт `__pycache__` в папке задания.

Файловые задания создают временные файлы в папке задания и удаляют их
через `trap`. Ввод-вывод принудительно в UTF-8 (`PYTHONUTF8=1`,
`PYTHONIOENCODING=utf-8`), чтобы кириллица в путях не ломала запуск.

## Частые проблемы

**`python` не найден.** Установи Python 3 с python.org и отметь
«Add Python to PATH». Либо задай `PYTHON` полным путём. Проверь,
что запускается именно Python 3: `python --version`.

**`python3` открывает Microsoft Store.** Это заглушка Windows. Используй
`python` или `py`, либо отключи псевдонимы приложений в параметрах
Windows.

**`IndentationError`.** В Python блок задают отступы, а не фигурные
скобки. Не смешивай табуляцию и пробелы. Обычно достаточно четырёх
пробелов на уровень.

**`SyntaxError: Missing parentheses in call to 'print'`.** Это синтаксис
Python 2. В Python 3 `print` — функция: `print("text")`.

**Вывод отличается переводом строки.** `print` добавляет `\n`,
`print(..., end="")` — нет. Тесты побайтовые: проверьте, нужен ли
перевод строки в конце.

**Число печатается не так.** `2.0` и `2` — разные строки. Для двух знаков
после точки используйте `f"{value:.2f}"`. Python всегда печатает точку,
а не запятую, — локаль на это не влияет.

**Логическое значение печатается не так.** Python выводит `True` и
`False` с заглавной буквы.

**`input()` падает на пустом вводе.** В интерактивном запуске это
`EOFError`. В автотестах пустой stdin подаётся только заданиям, где он
ожидается.

**Потоки дают разный вывод.** В заданиях порядок фиксируется через
`join()` или отдельные ячейки результата. Не полагайтесь на планировщик.
Помните про GIL: потоки в CPython не ускоряют счёт, но отлично
показывают гонки и синхронизацию.

**Файловое задание не находит файл.** Относительный путь считается от
текущего каталога. Запускайте тест из папки задания.

**Хочу пересобрать задания из спецификаций.** Из корня:

```bash
node build.js
```

Спецификации лежат в `specs/`. Это внутренний инструмент, для прохождения
заданий он не нужен.
